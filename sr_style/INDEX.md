# 车机 SR 风格化 · 代码索引

从观感版复制出来的试验工程，目标是把画面做成车机 SR（智驾感知可视化）的观感：
**低模 + 卡通着色 + 描边 + 语义配色**，同时保留原有的报警、派单、设备跟随业务层。

三个工程并存，互不影响：

| 目录 | 状态 |
| --- | --- |
| `../command_demo/` | 原观感版，最终交付，**不要改动** |
| `../sr_view/` | 扫描建图试验（上一版，压暗方案） |
| `sr_style/` | **本工程**，SR 风格化 |

## 三、风格化怎么实现的

### 3.1 语义平色（`style_mode.js`）

遍历场景树，给每个 `MeshStandardMaterial` / `MeshPhysicalMaterial` 注入片元代码。
材质按来源分三类取色：

1. 有 `userData.slug` 的 PBR 材质 → 查语义色板（十一类）；
2. 玻璃（`clearcoat > 0.5`）→ 单独一支；
3. 其它构件（列车、长椅、导向牌）→ 用材质自己的颜色，只压饱和度。

每类参数：`color` 底色、`noise` 原贴图亮度保留度、`rim` 边缘光、`sheen` 地面反光、
`bands` 明暗分档开关、`solid` 强制不透明。

### 3.2 卡通明暗

法线与固定光向点积，分三档（1.0 / 0.86 / 0.74），不做连续过渡。
树冠设 `bands = 0`：球体上分档会跑出一圈圈同心圆，俯视像甜甜圈。

### 3.3 边缘光与地面反光

菲涅尔项把物体从深色背景里勾出来；水平面再叠一层冷色高光，路面才有湿沥青质感。

### 3.4 距离雾

**不能用 `scene.fog`**：它在 `dithering_fragment` 之前执行，而我们在这之后重写颜色，
雾会被整段盖掉。所以在自己的片元里按 `distance(cameraPosition, world)` 混向背景色。
雾距随镜头距离每帧自适（`d = 跟随时 30，否则取轨道距离`，near = 1.1d，far = 3.6d）。

### 3.5 描边

合并后的静态几何复制一份，`side: BackSide`，顶点沿法线外扩，
外扩量 `normal * (-mv.z) * 0.0034`，屏幕线宽恒定。树材质的几何跳过。

### 3.6 背景

两像素宽的竖直渐变贴图当 `scene.background`。
**天空球优先级更高**，必须 `skyMesh.visible = false`，否则渐变根本看不见。

## 四、道路标线

原工程道路只有路面，**一条标线都没有**。车道级导航里路的辨识度全靠
「暗路面 + 亮边线 + 中间一条分道线」。数据包里只有道路多边形、没有车道线数据，
所以分两路做。

### 4.1 边线：几何（`road_marks.js`）

- 沿内外环铺 0.46 米宽亮边线，逐点斜接（`MITER_MIN = 0.42`，尖角截断防炸开）；
- 森林林道按中心点画 2.6 米实线 + 3.4 米间隔的虚线；
- 所有标线并进**一个** BufferGeometry，只占一次绘制调用；
- 标线材质带 `polygonOffset`（-9 / -18），否则会被路面的深度偏移压下去，变成断续虚线。

### 4.2 中线：距离场（`road_sdf.js`）

没有中线数据就换个思路：**算出每个点离路边多远**，中线自然就在 4 米处。

1. 用 canvas 把道路多边形奇偶填充成掩膜（1 米一格，整幅 1333 × 1079）；
2. 两遍倒角距离变换（chamfer 3-4），得到每格到路边的距离；
3. 编码成 8 位贴图（0~8 米），交给路面着色器按世界坐标采样。

着色器里：离边 3.72~4.28 米的窄带画成暖白中线，超过 5 米（路口）自动收掉；
同时按距离给路面一点起拱感，中间亮、靠边暗。一次计算约 100 毫秒，四场景共用。

### 4.3 地面分层的坑

地面是一层层几乎共面的薄片：草坪底盘 y=0、林地与校园底 y=0.02、路面 y=0.05。
远处深度精度只有十几厘米，必然打架。写实版颜色接近看不出来，
**平涂成一深一浅之后整片草地都是斜条纹**。不能靠抬高度解决（狗和人站在 y=0，
抬地面会把它们埋进去），改用 `polygonOffset` 按类别固定先后：绿化 1、铺装 2、路面 3。

## 五、扫描建图（沿用 `sr_view` 的方案）

跟随设备时触发，半径从零扩到 46 米：

- 圈外高于地面半米的片元 `discard`，建筑整块消失；
- 地面压到近黑；
- 地面叠一层 2 米网格 + 扫描亮环 + 旋转拖尾；
- 左下角 HUD 显示半径与进度。

注入顺序：**风格化先、扫描后**。两者改的是同一个 `gl_FragColor`，
后注入的代码后执行；顺序反了，扫描的压暗会被平色盖掉。
两边都用「保存上一段 `onBeforeCompile` 再链上去」的写法，不能直接赋值。

## 六、已知问题

1. **草地上有斜向条纹**（校园绿化带、小区周边）。原工程写实版同样存在，
   是草地贴图在大片平地上的摩尔纹；平涂后更容易被看成脏。
   排查过：不是描边、不是 GTAO、不是距离雾、不是未注入的材质。
2. **校园跟随视角偏空**。dog-1 常停在空地上，跟随时画面大半是草地。
   可以把设备巡检航点往建筑密集区收，或跟随时把机位再抬高一点。
3. **帧率未在真机测**。无头软件渲染只有 1–4 fps，不代表实际表现。
   材质注入不增加绘制调用，描边多一遍顶点，整体开销应低于原写实版。
4. **地铁站厅小**，46 米半径一次覆盖全站，看不出扩张过程。
