## 拓扑

```
浏览器
  │  https://blog.srlove.top
  ▼
OpenResty（1Panel 容器 1Panel-openresty-46yn，监听 80/81/443）
  ├── /aegis/…   →  /opt/1panel/www/aegis/…（宿主路径，容器内是 /www/aegis）
  └── /api/…     →  http://127.0.0.1:8791（宿主上的 Node 总线）
```

- 静态文件：宿主 `/opt/1panel/www/aegis/`，容器内 `/www/aegis/`。
- API：宿主 `/opt/aegis/`，systemd 服务 `aegis-api.service`，只监听 `127.0.0.1:8791`。
- nginx 片段：`/opt/1panel/www/conf.d/aegis-locations.inc`，由
  `blog.srlove.top.conf` 的 server 块 `include`。片段里的 `root /www;` 是**容器内路径**，
  对应宿主 `/opt/1panel/www/`；写成宿主 `/opt/1panel/www` 或 `/opt/aegis` 都会 404。
- 证书只覆盖 `blog.srlove.top` / `img.srlove.top`，**不要用 IP 直接访问 HTTPS**，会证书不匹配。

## 重新部署

### 1. 构建

```powershell
cd E:\code\demo\command_demo
$env:AEGIS_BASE='/aegis/'
npm run build
```

`vite.config.js` 里 `base: process.env.AEGIS_BASE || "./"`；`cssCodeSplit: true`
必须保留——手机页与大屏页的 `:root` 变量不同，合并 CSS 时手机页的 `--font` 会把大屏盖成 Inter。

### 2. 上传静态文件

把 `dist/` 打 zip，用 `tools/deploy/_upload.mjs` 传到 `/tmp/site.zip`，然后：

```bash
rm -rf /opt/1panel/www/aegis/assets
python3 -m zipfile -e /tmp/site.zip /opt/1panel/www/aegis
```

不要整目录删 `aegis/`，只换 `assets` 与 HTML 即可；旧 hash 资源留着也无害。

### 3. 更新 API（只在 `aegis_api.mjs` / `alert_bus.mjs` 改动时）

```bash
scp tools/deploy/aegis_api.mjs root@…:/opt/aegis/
scp tools/alert_bus.mjs       root@…:/opt/aegis/
systemctl restart aegis-api
systemctl status aegis-api --no-pager
```

### 4. 重载 nginx

```bash
docker exec 1Panel-openresty-46yn nginx -t
docker exec 1Panel-openresty-46yn nginx -s reload
```

配置有误时 `nginx -t` 会直接报行号；先修好再 reload。

## 运维命令

```bash
systemctl restart aegis-api      # 重启总线
journalctl -u aegis-api -f       # 看日志
curl -s http://127.0.0.1:8791/api/commands/health
docker exec 1Panel-openresty-46yn nginx -t
```

## 踩过的坑

1. **`conf.d` 里的 `.conf` 会被 http 级自动 include**。`aegis-locations.inc` 故意不用
   `.conf` 后缀，否则 `location` 出现在 http 级会报 `"location" directive is not allowed here`。
2. **容器内的路径不是宿主路径**。静态文件必须放在宿主 `/opt/1panel/www/`（容器 `/www`）下，
   放到 `/opt/aegis/` 容器看不见，表现为 `/aegis/` 404 而 `/api/` 正常。
3. **多入口 CSS 不能合并**。`cssCodeSplit:false` 时手机页的 `:root` 会覆盖大屏的 `--font`，
   线上字体退化成 Inter / 系统字体。构建配置已改为 `true`。
4. **二维码不是局域网地址**。公网部署时 `/api/alerts/info` 由 `aegis_api.mjs` 覆写，
   不再读网卡地址；本地开发仍走局域网 IP。
5. **静态与 API 同域**。前端仍请求根 `/api/…`，由 nginx 反代；不要改成 `/aegis/api`，
   否则所有客户端与 SSE 都要改路径。

## 安全

这是展台演示，页面与 API 都没有鉴权，任何拿到地址的人都能触发会诊/派单。
活动结束可 `systemctl stop aegis-api` 并移除 nginx include 下线。
服务器密码与私钥不要写进仓库；部署脚本只从 `SSH_HOST` / `SSH_USER` / `SSH_PASS` 环境变量读取。
