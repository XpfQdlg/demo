# AEGIS 界面重设计说明（手机 + 大屏）

版本：2026-11-09
前置文档：`07_移动预警接收页.md`、`08_四大模型场景应用.md`、`09_观众参与与大胆设想.md`
用途：说明这一轮 UI 重做的设计语言、信息架构，以及新加的一批互动能力怎么讲。

---

## 一、设计目标

展台上最常见的两个问题：**手机页像后台管理系统，观众看一眼就放下；大屏上信息太散，讲解员要来回指。**
这一轮按「AEGIS 指挥终端」重做视觉与信息架构：

- **手机端**：四个底部 Tab，一眼知道「现在有什么警、四个模型在干嘛、我能参与什么、我是什么角色」；
- **大屏**：同一套深空底 + 极光青/紫 + 暖琥珀语言，新增在线值班员、本场战报、语音指挥、第一视角回传；
- **共同原则**：大字号、强对比、少层级；一切互动都能在 30 秒内讲明白。

---

## 二、手机端信息架构

底部 Tab：

| Tab | 内容 | 讲解点 |
| --- | --- | --- |
| 预警 | 本场预警摘要 + 进行中/已处置列表 + 四档筛选 + 详情抽屉 | 「手机上就是接收端，一眼看到谁在处置、到哪一步」 |
| 模型 | 四模型能力卡 + 覆盖范围 + 应用链路；可打开完整四模型总览 | 「四个场景各一个模型，按场景路由」 |
| 参与 | 拍照上报 / 语音上报 / 巡检点打卡 / 模型盲盒 + 本场战报 + 我的等级 | 「观众能上手玩，而且真的会驱动大屏」 |
| 我的 | 值班员身份、积分等级、上报次数、本场在线人数与 Top 榜、声音/连接/重置 | 「扫码即入职，人人都是值班员」 |

### 视觉语言

- 底色：`#05070d` 深空黑，叠加青/紫极光径向渐变与细网格
- 主色：极光青 `#4ef0ff`、星云紫 `#8b7bff`；警示：火橙 `#ff6a4d`、琥珀 `#ffb347`、玫红 `#ff5fa2`
- 卡片：大圆角（18–24px）、玻璃渐变、1px 高光描边、极轻内阴影
- 字体：系统中文黑体；数字用等宽数字（`tabular-nums`）
- 动效：卡片入场、扫描线、会诊逐行点亮、呼吸光圈；全部遵循 `prefers-reduced-motion`

## 三、手机端新互动（全部可玩）

| 互动 | 路径 | 玩法 | 真实链路 |
| --- | --- | --- | --- |
| 拍照上报 | 参与 → 拍照上报 / 预警页「我要参与」 | 选场景 → 拍照或用演示照片 → 四模型会诊 → 一键上报 | POST `/api/commands` → 大屏切场景真出警 → 手机收观众上报卡片 |
| 语音上报 | 参与 → 语音上报 | 按住说话（有 Web Speech 用真实识别，没有则模拟识别），解析「场景 + 异常」→ 一键上报 | 同上 |
| 巡检点打卡 | 参与 → 巡检点打卡 | 模拟 AR 取景框，点四个巡检点之一扫描；可能「巡检正常」，也可能发现异常并可一键上报 | 上报走 visitor_report；正常则只提示 |
| 模型盲盒 | 参与 → 模型盲盒 | 5 轮现场图竞猜「属于哪个场景 / 哪里异常」，揭晓模型答案与置信度，累计积分/连对 | 得分写回 `/api/participants`，大屏榜单可见 |
| 值班员身份 | 我的 | 选角色：安保 / 消防 / 巡检 / 观众；昵称、等级、积分 | 注册到 `/api/participants`，大屏显示在线人数与角色点 |
| 现场回传 | 预警详情（观众上报卡片） | 机器狗出动后显示第一视角实时帧 | 大屏跟随出警时把 PIP 画布帧 POST `/api/frames`，手机轮询 |
| 本场战报 | 参与 / 我的 | 在线人数、上报次数、语音指令、最快处置、四模型命中 | 大屏同款数据来自 `/api/stats` |

**等级**：上报 +20 分、盲盒答对 +10、连对额外 +5；Lv1–Lv5（0 / 40 / 100 / 180 / 300）。

## 四、大屏新增

| 区域 | 内容 |
| --- | --- |
| 左上「值班员在线」 | 手机注册后实时显示人数与角色色点 |
| 右上「战报」按钮 / `B` | 打开本场 AI 安保战报：在线人数、观众上报、语音指令、最快处置、四模型命中条、值班员 Top 榜 |
| 模型条 | 显示当前模型 + 观众参与次数（沿用） |
| 语音指挥 | 手机发来 `voice_command`：切场景 / 回全局 / 跟随设备 / 直接上报 / 打开战报；大屏底部弹出「语音指挥 · …」提示 |
| 第一视角回传 | 观众上报出警、镜头自动跟随时，把 PIP 画布帧推到总线，手机详情实时显示 |
| 金色会诊面板 | 观众上报到达时四模型逐行会诊（沿用，视觉升级） |

大屏快捷键：`B` 战报，`Esc` 关战报/回全局，`H` 收起面板，`1–9` 跟随设备（沿用）。

## 五、怎么演示（推荐动线）

1. **开场**：大屏切校园，讲四模型与顶部模型条；手机扫码打开，指出「四个 Tab」。
2. **收警**：等自动报警或观众上报，手机上展示卡片、详情里的四模型链路与研判。
3. **参与**：手机「参与」Tab → 拍照上报（或语音上报），大屏金色会诊 + 自动跟随；手机收到「观众上报」卡片与回执。
4. **回传**：详情里展示机器狗第一视角回传帧，「这是他上报之后机器狗看到的画面」。
5. **榜单**：手机「我的」选值班员角色，做一轮模型盲盒攒积分；大屏按 `B` 打开本场战报，指在线人数、上报次数、四模型命中与 Top 榜。
6. **收尾**：语音指挥说一句「切到地铁」「打开战报」，大屏执行，说明语音也能驱动指挥端。

## 六、边界

- 手机端的识别/研判/盲盒答案均为**演示模拟**；拍照照片只在本机预览、不上传。
- 大屏的调度、报警、跟随、回传帧是真实渲染链路；总线只在开发服/preview 内有效。
- 语音识别依赖浏览器能力，不可用时自动降级为模拟识别文本（展台建议在安静环境用真实识别，否则直接用拍照上报）。
- AR 巡检点为**模拟取景框**，不调用真实摄像头；后续可替换为真实扫码/AR。
- 「现场回传」帧来自大屏第一人称小窗，不是真实机器狗摄像头；接真实设备后替换帧来源即可。
