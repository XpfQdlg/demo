# 机器人大会展台 Demo

**最终产物：`command_demo/cinematic.html`（观感版）。** 四场景 3D 实时画面，机器狗与人形机器人按 A* 巡检，
摄像头发现异常后派最近的空闲设备前往处置。

另有一个**手机端预警接收页**：大屏右上角点「手机」扫码，手机就能实时看到异常信息。
页面同时展示「四大模型 · 场景应用」：校园巡检、小区安防、地铁客运、森林火险四个场景模型，
每条预警带模型署名、置信度和研判理由，右上角「模型」可看四模型应用总览。

**观众还能直接参与**：手机点「我要参与」拍一张照片 → 四模型会诊 → 一键上报指挥中心 →
大屏切到对应场景、真的把机器狗派出去并自动跟随 → 手机收到「观众上报」预警与处置回执。

手机端已重设计为「AEGIS 移动指挥终端」：底部四个 Tab（预警 / 模型 / 参与 / 我的），
支持拍照上报、语音上报、巡检点打卡、模型盲盒、值班员身份与排行榜、机器狗第一视角回传；
大屏新增在线值班员、本场战报（`B`）、语音指挥与第一视角帧回传。见
[`docs/10_AEGIS界面重设计.md`](docs/10_AEGIS界面重设计.md)、
[`docs/07_移动预警接收页.md`](docs/07_移动预警接收页.md)、
[`docs/08_四大模型场景应用.md`](docs/08_四大模型场景应用.md) 与
[`docs/09_观众参与与大胆设想.md`](docs/09_观众参与与大胆设想.md)。

> 展台原型，场景与数据为模拟。不声称已在任何真实场地部署。

## 运行

**展台直接用离线包：双击 `command_demo/观感版演示.html`。** 8 MB，单文件，断网可用，不需要 Node。

开发或改代码：

```bash
cd command_demo
npm install
npm run dev
```

打开 <http://localhost:5179/>，根地址会跳到最终产物：

```text
http://localhost:5179/cinematic.html?scene=campus
```

场景参数 `campus` / `community` / `forest` / `subway`，可加 `&q=low|medium|high`。

手机看预警：大屏右上角点 **「手机」** 弹出二维码，手机与电脑连同一 Wi-Fi 后扫码打开
`http://<电脑局域网IP>:5179/phone`（302 到 `mobile.html`）。大屏上的发现、派单、到场、处置会
实时推到手机；只演示手机界面时，连不上总线会自动进入演示模式。细节见
[`docs/07_移动预警接收页.md`](docs/07_移动预警接收页.md)。

改完重新打包：

```bash
npm run bundle          # 输出 观感版演示.html
```

也可以双击 `command_demo/启动.bat`，它会安装依赖、起服务并打开浏览器。

## 手机看预警

| 步骤 | 说明 |
| --- | --- |
| 1 | 电脑起开发服：`cd command_demo && npm run dev` |
| 2 | 大屏页面右上角点「手机」，出现二维码与局域网地址 |
| 3 | 手机连同一 Wi-Fi，扫码打开 `/phone` |
| 4 | 顶栏显示「实时接收」后，大屏每次报警手机都会同步收到 |
| 5 | 想参与？点手机底部「我要参与」，拍一张照片，一键上报，大屏会真的出警 |

总线在开发服 / preview 里（`tools/alert_bus.mjs`），单文件离线包要实时接收需另起服务；
只给手机看界面的话，页面自己会落到演示模式。
