# 机器人大会展台 Demo

**线上：`https://blog.srlove.top/aegis/`（大屏）、`/aegis/tablet`（平板）、`/aegis/phone`（手机）。**
**离线：`command_demo/观感版演示.html`（单文件，双击即开）。** 一块大屏讲四个模型，两块小屏让人参与。

大屏是「AEGIS 城市风险中枢」，三个可选视觉：
默认是**建筑沙盘**（米白体块、鼠尾草绿地、摄影棚光，低模读成实体模型），`?look=night` 是夜间数字孪生，
`?look=map` 是 2D 作战地图。左侧四模型值守栏（校园巡检 / 小区安防 / 地铁客运 / 森林火险），
右侧事件流，底部四段链路。台上平板或自动演练触发时，整屏进入「四模型会诊」：主判模型给置信度，
另外三个模型独立复核，随后切到对应 3D 场景，就近调度机器狗或人形机器人前往处置。
**观众手机上报只在大屏右下角弹一条回执，不接管主画面**，3D 场景和讲解可以继续。

参与有两种，走同一条总线和同一套研判：

- **观众手机扫码**：大屏左下角二维码 → `/aegis/phone` → 拍一张现场照片 → 进度条自动分析并上报 →
  大屏切场景出警、右下角回执，手机收到「已上报」。
- **讲解员/领导用平板**：`/aegis/tablet` 舞台控制台，四张模型卡 × 三个情景，点一下即触发整屏会诊。

无人操作时，大屏会自己切场景，并每 80 秒左右自动演一遍「会诊 → 出警」，展台不会冷场。
现场流程、讲解词与故障排查见 [`docs/11_大会展台手册.md`](docs/11_大会展台手册.md)，
公网部署与运维见 [`docs/12_公网部署.md`](docs/12_公网部署.md)。

> 展台原型，场景与数据为模拟。识别与研判是模拟输出，调度与消息推送是真实跑的。
> 不声称已在任何真实场地部署。

## 运行

**展台直接用离线包：双击 `command_demo/观感版演示.html`。** 8 MB，单文件，断网可用，不需要 Node。

开发或改代码：

```bash
cd command_demo
npm install
npm run dev
```

打开 <http://localhost:5179/>，根地址会跳到最终产物：

```text
http://localhost:5179/cinematic.html?scene=campus
```

场景参数 `campus` / `community` / `forest` / `subway`，可加 `&q=low|medium|high`。

观众参与：扫大屏左下角二维码（或点右上角 **「手机」**），手机与电脑连同一 Wi-Fi 后打开
`http://<电脑局域网IP>:5179/phone`（302 到 `mobile.html`）。大屏上的发现、派单、到场、处置会
实时推到手机；只演示手机界面时，连不上总线会自动进入演示模式。细节见
[`docs/07_移动预警接收页.md`](docs/07_移动预警接收页.md)。

改完重新打包：

```bash
npm run bundle          # 输出 观感版演示.html
```

也可以双击 `command_demo/启动.bat`，它会安装依赖、起服务并打开浏览器。

## 手机看预警

| 步骤 | 说明 |
| --- | --- |
| 1 | 电脑起开发服：`cd command_demo && npm run dev` |
| 2 | 大屏页面右上角点「手机」，出现二维码与局域网地址 |
| 3 | 手机连同一 Wi-Fi，扫码打开 `/phone` |
| 4 | 顶栏显示「实时接收」后，大屏每次报警手机都会同步收到 |
| 5 | 想参与？点手机底部「我要参与」，拍一张照片，一键上报，大屏会真的出警 |

总线在开发服 / preview 里（`tools/alert_bus.mjs`），单文件离线包要实时接收需另起服务；
只给手机看界面的话，页面自己会落到演示模式。
